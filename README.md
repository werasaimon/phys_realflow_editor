# PhysRealFlow Editor

Редактор-просмотрщик для [PhysRealFlow](https://github.com/werasaimon/phys_realflow): окно OpenGL 3.0,
панели параметров каждого решателя, графики (сами открываются на ▶: энергия сцены, высота и скорость
выбранного тела; любая величина SDK или отладчика `Probe` — на самом графике), скриншоты и CSV из
командной строки. Физика — в SDK, подключённом как git-сабмодуль `extern/phys_realflow`; здесь
только Qt 6 и отрисовка.

## Сборка (Windows, Qt 6.7.3 MinGW)

```bat
git clone --recurse-submodules https://github.com/werasaimon/phys_realflow_editor.git
cd phys_realflow_editor
set PATH=C:\Qt\Tools\mingw1120_64\bin;C:\Qt\Tools\Ninja;%PATH%
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=C:/Qt/6.7.3/mingw_64
cmake --build build -j
run.cmd --preset 27
```

Модули Qt: Core, Gui, Widgets, OpenGL, OpenGLWidgets (графики рисуются самим редактором, Qt Charts не нужен). Обновить SDK до последнего коммита:
`git submodule update --remote extern/phys_realflow`.

## Командная строка

Без ключей редактор открывается на конструкторе в режиме правки. При самом первом запуске — сцена «Горка и башня» с подсказкой, дальше — пустой пол.

| Ключ | Смысл |
|---|---|
| `--scene file.rfscene` | открыть сцену конструктора из файла |
| `--preset N` | загрузить готовую сцену `N` из реестра `samples/` SDK и запустить |
| `--frames M` | сколько кадров посчитать перед снимком (по умолчанию 120) |
| `--screenshot file.png` | сохранить PNG 3D-окна и выйти; с `--window` — всего окна с панелями; сцену конструктора — после `--frames` кадров игры, с `--edit` — в режиме правки, с `--camera` — через активную камеру сцены |
| `--csv file` | сохранить в CSV каждый посчитанный кадр — энергию сцены (кинетическую, потенциальную, полную), показания решателей и все каналы SDK и `Probe` — и выйти |
| `--size WxH` | размер окна (по умолчанию `1600x950`) |
| `--software-gl` | рендер на процессоре (Mesa llvmpipe) |
| `--dump-icons dir` | записать все иконки редактора в PNG (для документации) и выйти |
| `--self-test` | проверить конструктор: арифметику гизмо, перетаскивание мышью, выбор лучом и рамкой, клавиши, камеру, меню, правку / пуск / стоп, компоненты и коллайдеры, многое сразу, свет и камеры, первую минуту; код возврата = число ошибок; с `--shots dir` — ещё и снимки |
| `--gizmo-shots dir` | снимки гизмо (W, E, R, поворот в процессе) на выделенном кубе и выйти |
| `--first-start` | открыть как при самом первом запуске: сцена «Горка и башня» и подсказка |
| `--thumbnail` | только 3D-вид, без окна на экране (так рисуются картинки «Примеров») |
| `--gallery-shot file.png` | нарисовать все картинки «Примеров», сохранить галерею в PNG и выйти |

## Конструктор сцен

### Первая минута

При самом первом запуске открывается живая сцена «Горка и башня»: мяч на горке, башня из кубиков, бочка, ёлка. Жёлтый пузырь показывает, что нажать:

1. **«Куб»** сверху — куб появляется в воздухе, на 0,8 м над полом;
2. плитку **«Твёрдое»** справа — куб становится телом (коллайдер «Авто» добавляется сам);
3. **▶ Пуск** — куб падает и отскакивает, мяч скатывается и роняет башню.

Пузырь уходит после первого действия и больше не появляется. Повторить первый запуск можно ключом `--first-start`. Все готовые сцены — кнопка **«Примеры»**: плитки с картинками. Картинки редактор рисует сам, один раз, в фоне, и хранит в папке кэша пользователя.

### Правка → Пуск → Стоп

Как в Unity, Unreal и Blender:
- **Правка** (так открывается редактор) — обычный 3D-редактор. Кнопки создают *только геометрию*: ничего не падает и не считается.
- **▶ Пуск** (пробел) строит симуляцию из нарисованного. **⏸ Пауза** — стоп-кадр, **Шаг** («.») — один кадр.
- Во время игры инспектор живой: включите «Мягкое» падающему кубу воды, и он продолжит падать желе. Пересобирается только этот объект.
- **■ Стоп** (Esc или Shift+пробел) возвращает сцену такой, какой она была до ▶. Правки, сделанные во время игры, не сохраняются, как в Unity.
- Игру не спутать с Правкой: вид обведён оранжевой рамкой, сверху полоса «▶ ИГРА — правки не сохранятся». Внизу вида всегда большие **▶ ⏸ ■**.
- **K** (или кнопка на полосе) — «Сохранить положения из симуляции», как Keep Simulation Changes в Unreal: живые позы выбранных объектов (или всех) останутся после ■ Стоп; после Стопа один Ctrl+Z возвращает их.
- Тело в игре выглядит так же, как в Правке: одна и та же форма, автосглаживание по углу 35° (шар круглый, у куба рёбра), уснувшие тела не темнеют (темнеют только со слоем «Сон» панели исследования).

Если правку нельзя применить на лету (например, включение газа меняет весь мир), редактор останавливается, сохраняет правку и в полосе сверху инспектора пишет, почему нужен ▶, с кнопкой «▶ Пуск».

### Геометрия и коллайдер

**Геометрия** — то, как объект выглядит. **Коллайдер** — то, чем он ударяется о другие. Физика двигает и поворачивает геометрию, но никогда её не меняет: сфера с коллайдером «Капсула» остаётся сферой, просто сталкивается как капсула. Так устроено в Houdini (форма столкновений пакованного тела отдельно от геометрии, её показывает guide geometry) и в Unity (компонент Collider рядом с MeshRenderer).

- Коллайдер — отдельный компонент. **Один коллайдер** — неподвижное препятствие (пол, стена, горка). **Твёрдое тело + коллайдер** — тело, которое падает и катится.
- Добавили «Твёрдое тело» — коллайдер «Авто» добавляется сам. Убрали коллайдер — карточка твёрдого тела предупреждает: «без коллайдера тело провалится сквозь всё» и даёт кнопку «Добавить коллайдер».
- Виды: **Авто** (сама форма; рядом написано, во что она превратилась: «Авто → сфера»), **Коробка**, **Сфера**, **Капсула**, **Выпуклая оболочка**, **Точно** (форма, разбитая на выпуклые части). «Подогнать под геометрию» берёт размер из формы; без галочки размер, сдвиг и поворот задаются числами.
- Коллайдер виден **тонким каркасом** поверх формы: у выделенного объекта всегда, у всех — кнопкой «Коллайдеры» сверху. Зелёный — тело движется, серый — неподвижное препятствие, тусклый — тело уснуло. В правке каркас стоит там, где объект; при игре едет вместе с телом.

### Инспектор: «Сцена» и «Объект»

Справа одна панель с двумя вкладками, как Hierarchy и Inspector в Unity. Выбор объекта открывает «Объект»; ничего не выбрано — подсказка.
- **Сцена** — всё, что есть в сцене: имя и компоненты («Куб 1 — твёрдое, коллайдер»), **глаз** (скрытое не участвует в расчёте) и **замок** (мышь не выделяет и не двигает — так закреплён пол). Ниже «Мир»: тяжесть, коробка, воздух.
- **Объект**, сверху вниз: плитки-палитра компонентов; карточка **«Объект»** (имя, глаз, замок, цвет, где, поворот, размер); карточка **«Геометрия»** (форма или файл модели — «физика её не меняет»); затем **только добавленные компоненты**, каждый — складная карточка с иконкой и ✕; внизу **«+ Добавить компонент»** — меню того, чего у объекта ещё нет.

Голый объект — только «Объект» и «Геометрия». Что-то не сработает — полоса сверху инспектора говорит почему и чинит одной кнопкой («Огню нужен воздух — Включить воздух»).

| Компонент | Что это физически | Что включает сам |
|---|---|---|
| Твёрдое тело | не гнётся; падает, сталкивается, катится; плотность, трение, упругость, начальная скорость | коллайдер «Авто» |
| Коллайдер | чем объект сталкивается; один — неподвижное препятствие | — |
| Мягкое тело | гнётся и пружинит, как желе | — |
| Жидкость | объём формы заполняется водой | — |
| Ткань | плоскость становится полотном: висит, развевается, рвётся (из модели — пока нет) | вешает на прут и поднимает на 1,2 м |
| Магнит | магнитный диполь: магниты притягиваются и поворачиваются друг к другу | твёрдое тело с коллайдером, если объект ни из чего не сделан |
| Излучатель | дымный (или горячий, или водяной) след | воздух |
| Горит | загорается от пламени и горит, ткань прогорает | воздух с кислородом |
| Тепло | горячее пятно: воздух над ним поднимается | воздух |

Из чего сделан объект — одно за раз: Твёрдое, Мягкое, Жидкость или Ткань. Коллайдер к этому ряду не относится.

### Управление

Сверено с документацией Blender, Houdini, Unity, Maya, 3ds Max и Unreal: [docs/controls.md](docs/controls.md). Правило: как у большинства, а где у всех по-разному — как проще. Строка состояния внизу всегда пишет, что сейчас делают кнопки мыши и клавиши. Подсказка каждой кнопки показывает её клавишу.

**Схема мыши «Простая»** (по умолчанию; «Как в Blender» и «Как в Maya/Unity» — в меню Вид → Управление, при первом запуске редактор спросит один раз):

| Кнопка | Что делает | С Alt (как в Maya, Unity, Unreal, Houdini) |
|---|---|---|
| ЛКМ | выбрать, рамка с пустого места, гизмо; камеру не двигает никогда | вращать камеру |
| ПКМ | тянуть — вращать вокруг точки под курсором; щелчок — меню; держать + W A S D — полёт (Q / E вниз / вверх, Shift быстрее) | зум |
| СКМ | панорама | панорама |
| колесо | зум к курсору | — |

В углу вида — **куб навигации**: щелчок по шарику оси смотрит вдоль неё (Y — сверху), перетаскивание вращает вид.

| Действие | Клавиши |
|---|---|
| выбрать; то, что позади | ЛКМ; ещё раз в то же место |
| добавить / убрать из выбора | Shift+ЛКМ или Ctrl+ЛКМ; рамка: Shift — добавить, Ctrl — убрать |
| выбрать всё / ничего | Ctrl+A / Ctrl+Shift+A |
| инструменты: выбор, двигать, вращать, масштаб | Q, W, E, R |
| во время перетаскивания: ось; плоскость | X / Y / Z; Shift+X / Y / Z |
| шаг (0,1 м, 15°, 10 %); точнее | держать Ctrl; держать Shift |
| отменить перетаскивание | Esc или ПКМ |
| оси мира или свои | L или кнопка «Мир / Свои» |
| по полу | Shift + перетаскивание объекта |
| показать выбранное (без выбора — всё); всё | F или двойной щелчок; Home |
| виды сверху / спереди / справа | Numpad 7 / 1 / 3, с Ctrl — с обратной стороны |
| удалить; дублировать | Del или Backspace; Ctrl+D |
| скрыть; показать скрытое | H; Alt+H |
| отменить; повторить | Ctrl+Z; Ctrl+Y или Ctrl+Shift+Z |
| пуск / пауза; стоп; шаг | пробел; Esc; «.» |
| сохранить положения из симуляции | K |
| найти любую команду по имени | Ctrl+K |
| Лаборатория; графики внизу | F8; F9 |
| размер гизмо | + / − |

В схеме «Как в Blender» есть и клавиши Blender: G / R / S — двигать, вращать, масштабировать за мышью (затем X / Y / Z и набранное число: «G X 0.5 Enter» сдвигает ровно на полметра), X — удалить, Shift+D — копия.

**Гизмо** рисуется поверх всего и не меняет размер на экране. X красный, Y зелёный, Z синий, ручка под мышью жёлтая. Стрелка двигает по оси, квадратик — в плоскости, белый кружок — в плоскости экрана. Кольца вращают, внешнее белое кольцо — вокруг взгляда. Кубики масштабируют по оси, квадрат в центре — целиком. У курсора видно, сколько сдвинули («X +0.350 м»). Каждое перетаскивание — один шаг отмены; работает сразу на всех выбранных объектах.

### Много объектов сразу

Подробно — в [docs/controls.md](docs/controls.md), раздел 6.

| Что | Как |
|---|---|

| выбор | меню ПКМ и Правка: «Выбрать все такие же», «Выбрать все с компонентом ▸», «Инвертировать выбор» |

### Свет и камеры

Подробно — в [docs/controls.md](docs/controls.md), раздел 7. «Свет ▾» на панели сверху — солнце, лампа, прожектор;
«Камера» — камера там, где вид редактора. Каркасы выбираются щелчком и двигаются гизмо; карточки «Свет» и «Камера» в
инспекторе. «Смотреть через камеру» (или Вид → «Камеры ▸») делает вид камерой: движение вида двигает камеру, Esc
возвращает вид редактора. Нет ни одного источника — сцена освещена светом редактора, как раньше.

**Тени — по галочке.** У каждого источника в карточке «Свет» есть «Отбрасывает тени». Новое солнце бросает тень сразу,
лампа и прожектор — после галочки: каждая тень — лишний проход рендера каждый кадр (у лампы шесть — по грани куба
вокруг неё), поэтому у них она сначала выключена, как в Blender и Unity. Солнце и прожектор рисуют карту глубины
(Williams 1978), лампа — куб расстояний; край смягчён несколькими соседними выборками (PCF). Тени рисуются не больше
чем от 4 источников сразу: сначала солнца, потом самые яркие для глаза; остальных строка состояния называет по именам.
Тень бросают твёрдые тела, геометрия, ткань и мягкие тела; частицы жидкости — пока нет.

**Файлы.** «Сцена» → «Новая пустая сцена» / «Открыть…» / «Сохранить…» (Ctrl+N / Ctrl+O / Ctrl+S).
Формат `*.rfscene` — простой текст, по строке на факт; его можно читать и править руками:

```
# PhysRealFlow scene
world gravity 0 -9.81 0 size 4 3 4 gas 1 magneticGas 0
entity "Штора"
  object id 5 visible 1 locked 0
  shape plane size 1 0.02 1.1 position 0.8 1.35 0.4 rotation 90 0 0 color 0.9 0.85 0.72
  cloth areaDensity 0.2 bendCompliance 0.001 tearable 1 pinned 16
  flammable
end
```

Примеры в `examples/`:
- `midas.rfscene` — всё сразу: два магнита тянутся друг к другу, ящик летит и дымит, хлопковая штора
  висит над горелкой и загорается, желейный шар подпрыгивает;
- `magnets.rfscene` — два неодимовых магнита в невесомости притягиваются, стрелка компаса поворачивается по полю;
- `cradle-and-cubes.rfscene` — колыбель Ньютона из шести стальных шаров на полу (e = 1, без трения,
  зазор 1 см), башня кубиков и желейный шар.

Дальше: граф ролей — роли как узлы, которые соединяются с формами (в меню он пока выключен).

**Путеводитель по интерфейсу с картинками:** [docs/ui-guide.md](docs/ui-guide.md).

**Лаборатория (F8)** — отладчик физики в духе PhysX PVD прямо в редакторе: слои отрисовки движка по группам с легендой цветов и быстрыми наборами, карточка точки контакта или тела по щелчку (числа с единицами, «Следить за парой» для GJK / EPA, правый щелчок — график канала), лента последних 600 кадров с точным показом любого из них и время шага физики по стадиям; подробно — [docs/ui-guide.md, раздел 12](docs/ui-guide.md#12-лаборатория-что-считает-движок).

**Графики (F9)** открываются сами на первом ▶ и сразу рисуют энергию сцены — движения, высоты и полную; выбранное тело добавляет свои «Высота» и «Скорость». Остальное — на самом графике: ▾ у заголовка (другая величина или ещё линия), щелчок по легенде (спрятать, двойной — оставить одну), правый щелчок (раскладки «Наложить / Дорожками / Нормировать», CSV, картинка, момент в Лаборатории); память и время рисования ограничены при любой длине прогона; подробно — [docs/ui-guide.md, раздел 13](docs/ui-guide.md#13-графики-как-меняется-сцена).
