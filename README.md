# PhysRealFlow Editor

Редактор-просмотрщик для [PhysRealFlow](https://github.com/werasaimon/phys_realflow): окно OpenGL 3.0,
панели параметров каждого решателя, графики любого канала отладчика `Probe`, скриншоты и CSV из
командной строки. Физика — в SDK, подключённом как git-сабмодуль `extern/phys_realflow`; здесь
только Qt 6 и отрисовка.

## Сборка (Windows, Qt 6.7.3 MinGW)

```bat
git clone --recurse-submodules https://github.com/werasaimon/phys_realflow_editor.git
cd phys_realflow_editor
set PATH=C:\Qt\Tools\mingw1120_64\bin;C:\Qt\Tools\Ninja;%PATH%
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=C:/Qt/6.7.3/mingw_64
cmake --build build -j
run.cmd --preset 27
```

Модули Qt: Core, Gui, Widgets, OpenGL, OpenGLWidgets, Charts. Обновить SDK до последнего коммита:
`git submodule update --remote extern/phys_realflow`.

## Командная строка

| Ключ | Смысл |
|---|---|
| `--preset N` | загрузить сцену `N` из реестра `samples/` SDK и запустить |
| `--frames M` | сколько кадров посчитать перед снимком (по умолчанию 120) |
| `--screenshot file.png` | сохранить PNG окна и выйти |
| `--csv file` | сохранить все каналы `Probe` и графики сцены в CSV и выйти |
| `--size WxH` | размер окна (по умолчанию `1600x950`) |
| `--software-gl` | рендер на процессоре (Mesa llvmpipe) |

## Что где

```
src/   MainWindow (панели, меню сцен из реестра SDK), Viewport (OpenGL: тела, частицы, срезы, объём дыма,
       силовые линии, отладочная отрисовка Probe), FluidSurfaceRenderer (экранная вода), PlotPanel
       (графики любого канала), SimController (поток расчёта), ParamForm, OrbitCamera, ViewportTools
extern/phys_realflow   SDK: src/ (решатели), samples/ (сцены), tests/, docs/
```

Документация физики, формулы и таблицы проверок — в SDK: `extern/phys_realflow/docs/`.

## Конструктор сцен

Сцену можно собрать без кода — в панели «Конструктор» (справа; меню «Вид» → «Конструктор»).

1. **Кнопки** «Куб», «Сфера», «Цилиндр», «Конус», «Плоскость» добавляют форму. Новые тела ставятся сеткой 5 × 5 над полом, чтобы не пересекаться. Плоскость — неподвижная плита 3 × 3 м: пол, стол или наклонная плоскость, если её повернуть.
2. **Список** показывает всё, что есть в сцене, и кем это является («Куб 1 — твёрдое, магнит»). Delete удаляет выбранное, «Дублировать» ставит копию сверху.
3. **Инспектор** под списком: имя, форма, размер, положение, поворот, цвет и **роли**. Роль — это галочка на группе, она говорит форме, кто она:

| Роль | Что это физически | Решатель SDK |
|---|---|---|
| Твёрдое тело | не гнётся; сталкивается, катится, скользит; плотность, трение, упругость удара, начальная скорость и вращение; «неподвижное» — стена или стол | `RigidWorld` |
| Мягкое тело | гнётся и пружинит; плотность, жёсткость | частицы, shape matching |
| Жидкость | объём формы заполняется водой | частицы PBF |
| Магнит | магнитный диполь с моментом в А·м²: магниты притягиваются и поворачиваются друг к другу; в плазме толкает газ | `scene/Magnets` |
| Источник тепла | горячее пятно в газе: тёплый воздух поднимается и несёт дым (нужен газ) | `GasSolver` |

Твёрдое, мягкое и жидкость — из чего сделана форма, поэтому одновременно включается только одна из этих ролей. Магнит и тепло добавляются к ним.

4. **Мир**: гравитация, размер коробки (пол на y = 0), «Газ» (воздух на сетке) и «Плазма (МГД)».

Любая правка сразу перезапускает сцену. Правки копятся 150 мс, так что прокрутка числа не перезагружает сцену на каждом шаге. Щелчок по телу в окне выделяет его в списке.

**Файлы.** «Сцена» → «Новая пустая сцена» / «Открыть…» / «Сохранить…» (Ctrl+N / Ctrl+O / Ctrl+S). Формат `*.rfscene` — простой текст, по строке на факт; его можно читать и править руками:

```
# PhysRealFlow scene
world gravity 0 0 0 size 4 3 4 gas 0 magneticGas 0
entity "Магнит A"
  shape box size 0.04 0.02 0.02 position -0.08 0.5 0 rotation 0 0 0 color 0.85 0.2 0.2
  rigid density 7500 friction 0.5 restitution 0.2 fixed 0 velocity 0 0 0 spin 0 0 0
  magnet moment 2 0 0
end
```

Примеры лежат в `examples/`:
- `magnets.rfscene` — два неодимовых магнита в невесомости притягиваются, стрелка компаса поворачивается по полю;
- `cradle-and-cubes.rfscene` — бильярдная колыбель Ньютона из шести стальных шаров (e = 1, без трения, зазор 1 см), башня кубиков и желейный шар. Сейчас шары после удара катятся вместе, одним комком, со скоростью 2/6 от начальной, как при неупругом ударе. Это известный дефект решателя твёрдых тел (табло SDK, `docs/09-benchmarks.md`): сцена оставлена, чтобы исправление было видно.

Граф ролей (роли как узлы, которые соединяются с формами) — следующий шаг; в меню он пока выключен.
