# PhysRealFlow Editor

Редактор-просмотрщик для [PhysRealFlow](https://github.com/werasaimon/phys_realflow): окно OpenGL 3.0,
панели параметров каждого решателя, графики любого канала отладчика `Probe`, скриншоты и CSV из
командной строки. Физика — в SDK, подключённом как git-сабмодуль `extern/phys_realflow`; здесь
только Qt 6 и отрисовка.

## Сборка (Windows, Qt 6.7.3 MinGW)

```bat
git clone --recurse-submodules https://github.com/werasaimon/phys_realflow_editor.git
cd phys_realflow_editor
set PATH=C:\Qt\Tools\mingw1120_64\bin;C:\Qt\Tools\Ninja;%PATH%
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=C:/Qt/6.7.3/mingw_64
cmake --build build -j
run.cmd --preset 27
```

Модули Qt: Core, Gui, Widgets, OpenGL, OpenGLWidgets, Charts. Обновить SDK до последнего коммита:
`git submodule update --remote extern/phys_realflow`.

## Командная строка

Без ключей редактор открывается на конструкторе в режиме правки: пол, на который можно что-нибудь поставить.

| Ключ | Смысл |
|---|---|
| `--scene file.rfscene` | открыть сцену конструктора из файла |
| `--preset N` | загрузить готовую сцену `N` из реестра `samples/` SDK и запустить |
| `--frames M` | сколько кадров посчитать перед снимком (по умолчанию 120) |
| `--screenshot file.png` | сохранить PNG 3D-окна и выйти; с `--window` — всего окна с панелями; сцену конструктора — после `--frames` кадров игры, с `--edit` — в режиме правки |
| `--csv file` | сохранить все каналы `Probe` и графики сцены в CSV и выйти |
| `--size WxH` | размер окна (по умолчанию `1600x950`) |
| `--software-gl` | рендер на процессоре (Mesa llvmpipe) |
| `--dump-icons dir` | записать все иконки редактора в PNG (для документации) и выйти |
| `--self-test` | проверить конструктор: арифметику гизмо, настоящее перетаскивание мышью, выбор лучом, меню, правку / пуск / стоп, смену роли во время игры; код возврата = число ошибок; с `--shots dir` — ещё и снимки |
| `--gizmo-shots dir` | снимки гизмо (W, E, R, поворот в процессе) на выделенном кубе и выйти |

## Что где

```
src/   MainWindow (окно, большая панель «Создать», меню), Viewport (OpenGL: тела, частицы, срезы,
       объём дыма, силовые линии, контур выделенного, перетаскивание Shift+мышь, отладочная
       отрисовка Probe), SceneBuilder (+Panels: конструктор сцен), ObjectInspector (блок «Объект»
       для любой вещи сцены), RoleBar (кнопки ролей), InspectorWidgets (поля x/y/z, складные
       разделы), Icons (иконки, нарисованные кодом), SelfTest, FluidSurfaceRenderer, PlotPanel,
       SimController, ParamForm, OrbitCamera, ViewportTools
examples/              сцены конструктора: midas, magnets, cradle-and-cubes
extern/phys_realflow   SDK: src/ (решатели), samples/ (сцены), tests/, docs/
```

Документация физики, формулы и таблицы проверок — в SDK: `extern/phys_realflow/docs/`.

## Конструктор сцен

**Правка → Пуск → Стоп**, как в Unity, Unreal и Blender:
- **Правка** (так открывается редактор) — обычный 3D-редактор. Кнопки создают *только геометрию*: форма стоит там, где её поставили, ничего не падает и не считается.
- Двигайте, вращайте, масштабируйте, импортируйте модель; роли (твёрдое, ткань, магнит…) пока лишь помечают объект.
- **▶ Пуск** (пробел) строит симуляцию из нарисованного, и физика оживает. **⏸ Пауза** — стоп-кадр, **Шаг** (S) — один кадр.
- Во время игры инспектор живой: включите «Мягкое» падающему кубу воды, и он продолжит падать желе. Пересобирается только этот объект.
- **■ Стоп** (Shift+пробел) возвращает сцену такой, какой она была до ▶: куб на месте, штора целая. Правки, сделанные во время игры, не сохраняются, как в Unity.

Сцена устроена в три слоя. **Источник** — геометрия, физика её не разрушает. **Объект** — источник с положением и ролями; его правят гизмо и инспектор. **Метаобъект** — физика, которую роль создаёт при игре. Если правку нельзя применить на лету (например, включение газа меняет весь мир), редактор останавливается, сохраняет правку и пишет, почему нужен ▶.

**Сверху — «Создать».** Кнопки «Куб», «Сфера», «Цилиндр», «Конус», «Плоскость» и «Модель» (OBJ / STL: только форма, самая длинная сторона — 1 м). Новая форма стоит на полу на свободном месте. Рядом — ▶ ⏸ ■, «Шаг», «Отменить / Повторить» (Ctrl+Z, Ctrl+Shift+Z). Справа — «Примеры ▾» (готовые сцены SDK), «Графики» и «Эксперт» (прежние панели решателей).

**Слева — инструменты**, как в Blender: Выбор (Q), Перемещение (W), Вращение (E), Масштаб (R) и оси «Мир / Свои» (X).

**Гизмо** на выделенном объекте рисуется поверх всего и не меняет размер на экране. Цвета: X красный, Y зелёный, Z синий, ручка под мышью жёлтая.
- **W — перемещение:** стрелка двигает по оси, квадратик — в плоскости (он в четверти, повёрнутой к вам), белый кружок в центре — в плоскости экрана.
- **E — вращение:** кольцо вращает вокруг оси, внешнее белое кольцо — вокруг взгляда. Дальняя половина колец притушена, поворот показан сектором.
- **R — масштаб:** кубик тянет по оси, квадрат в центре — целиком.
- Перетаскивание начинается после 3 пикселей: щелчок объект не сдвигает. Пока тянете, остальные ручки гаснут, вдоль оси идёт тонкая направляющая, а у курсора видно, сколько сдвинули («X +0.350 м», «Y +45.0°», «×1.20»).
- **Ctrl** — шаг: 0,1 м, 15°, 10 %. **Shift** — точно: мышь в 10 раз медленнее. **Esc** или правая кнопка отменяют перетаскивание.
- Каждое перетаскивание — один шаг отмены. Числа в инспекторе меняются вместе с объектом.

**Клавиши как в Blender.** G — двигать за мышью без ручек, Shift+R — вращать, Shift+S — масштабировать. Затем X / Y / Z ограничивают ось: первое нажатие — ось мира, второе — своя ось объекта, третье снимает ограничение. Набранное число задаёт точное значение: «G X 0.5 Enter» сдвигает ровно на полметра. Enter или левая кнопка подтверждают, Esc или правая кнопка отменяют.

**Выбор лучом.** Щелчок выделяет то, что ближе всего под курсором, по настоящей геометрии, а не по рамке. Повторный щелчок в то же место (в пределах 4 пикселей и 1,5 с, камера не двигалась) выделяет следующий объект позади, потом ещё дальше и снова ближний; у курсора видна подсказка «2 / 3: Штора». Alt+щелчок всегда берёт следующий. Выделенное обведено оранжевым контуром по силуэту, объект под мышью — бледным белым; геометрия без роли окружена едва заметной линией. Esc снимает выделение, Shift+перетаскивание двигает объект по полу.

**Правая кнопка — меню**, как quad menu в 3ds Max. Щелчок правой без перетаскивания сначала выделяет объект под курсором, потом открывает меню:
- инструменты: Выбор, Перемещение, Вращение, Масштаб;
- система координат: Мировая или Локальная;
- для выделенного: Показать (F), Дублировать, Удалить, Скрыть, Заблокировать и подменю «Роль».

Меню, панель инструментов и клавиши — одно и то же состояние. Правое перетаскивание, как и раньше, двигает камеру.

| Действие | Мышь / клавиши |
|---|---|
| выбрать; то, что позади | ЛКМ; ещё раз в то же место или Alt+ЛКМ |
| двигать / вращать / масштаб | W / E / R и ручки гизмо; G / Shift+R / Shift+S — за мышью |
| ось; точное число; шаг; точно | X Y Z; набрать число; Ctrl; Shift |
| оси мира или свои | X (вне перетаскивания) или кнопка «Мир / Свои» |
| по полу | Shift + перетаскивание объекта |
| отменить перетаскивание | Esc или ПКМ |
| меню | ПКМ (щелчок) |
| камера | колесо зажато — вращение, Shift+колесо или ПКМ-тяга — сдвиг, прокрутка — масштаб, F — показать |
| пуск, пауза, стоп, шаг | пробел, пробел, Shift+пробел, S |

**Справа — «Сцена» и «Инспектор»**, как список объектов и свойства в 3D-пакетах.
- *Сцена* — всё, что есть в сцене: имя и роли («Куб 1 — твёрдое, магнит»), **глаз** (скрытое не участвует в расчёте) и **замок** (мышь не выделяет и не двигает — так закреплён пол). Внизу раздел «Мир»: тяжесть, коробка, газ, плазма.
- *Инспектор* выделенного: иконка, имя, значки ролей и **кнопки ролей**. Ниже блок **«Объект»** — имя, глаз, замок, цвет, где, поворот; он одинаков для любой вещи сцены. Затем **«Форма»** и разделы только включённых ролей.

**Роли — кнопки с картинками.** Верхний ряд — из чего сделана форма, одна роль за раз. Повторное нажатие снимает роль: форма снова только геометрия. Нижний ряд — что она ещё делает, сколько угодно ролей сразу. Роль включает только то, что нужно ей самой: создание формы роль не назначает.

| Кнопка | Что это физически | Что включает сама |
|---|---|---|
| Твёрдое | не гнётся; падает, сталкивается, катится; плотность, трение, упругость, начальная скорость; «неподвижное» — стена, стол | — |
| Мягкое | гнётся и пружинит, как желе | — |
| Жидкость | объём формы заполняется водой | — |
| Ткань | плоскость становится полотном: висит, развевается, рвётся по нитям (из модели — пока нет) | вешает её на прут (верхний край) и поднимает на 1.2 м |
| Магнит | магнитный диполь: магниты притягиваются и поворачиваются друг к другу | делает форму твёрдым телом, если она ни из чего не сделана |
| Дым | дымный (или горячий, или водяной) след, где бы форма ни была | газ |
| Горит | загорается от пламени и горит, ткань прогорает | газ с кислородом |
| Тепло | горячее пятно: воздух над ним поднимается | газ |

**Файлы.** «Сцена» → «Новая пустая сцена» / «Открыть…» / «Сохранить…» (Ctrl+N / Ctrl+O / Ctrl+S).
Формат `*.rfscene` — простой текст, по строке на факт; его можно читать и править руками:

```
# PhysRealFlow scene
world gravity 0 -9.81 0 size 4 3 4 gas 1 magneticGas 0
entity "Штора"
  object id 5 visible 1 locked 0
  shape plane size 1 0.02 1.1 position 0.8 1.35 0.4 rotation 90 0 0 color 0.9 0.85 0.72
  cloth areaDensity 0.2 bendCompliance 0.001 tearable 1 pinned 16
  flammable
end
```

Примеры в `examples/`:
- `midas.rfscene` — всё сразу: два магнита тянутся друг к другу, ящик летит и дымит, хлопковая штора
  висит над горелкой и загорается, желейный шар подпрыгивает;
- `magnets.rfscene` — два неодимовых магнита в невесомости притягиваются, стрелка компаса поворачивается по полю;
- `cradle-and-cubes.rfscene` — колыбель Ньютона из шести стальных шаров на полу (e = 1, без трения,
  зазор 1 см), башня кубиков и желейный шар.

Дальше: граф ролей — роли как узлы, которые соединяются с формами (в меню он пока выключен).
